# Large-file exception ledger

The repository quality gate limits production modules to 800 lines and test
modules to 1,500 lines. There are currently **no exceptions**. New exceptions
are not permitted without a non-growing budget and an evidence-backed
decomposition plan recorded here.

Any proposed exception is a temporary migration budget, not an endorsement of
the file size. Prefer extracting a cohesive module or test suite first.
